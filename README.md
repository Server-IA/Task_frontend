# TaskFlow — Frontend

SPA de TaskFlow (gestor de tareas inspirado en Plane). Consume la API de `Task_backend`.

## Requisitos

- Node.js 22+
- El backend corriendo en `http://localhost:8080` (ver su README)

## Cómo levantarlo

```bash
npm install
cp .env.example .env
npm run dev            # http://localhost:5173
```
